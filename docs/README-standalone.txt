SolidWorks 模型体检 (Model Inspector)  v1.0
================================================

一个 SolidWorks 2025 加载项，用来批量检查模型问题。
它不是"教你操作"的工具，而是"替你检查"的工具。


一、它能做什么
--------------
· 扫描当前文档：特征重建错误、断链文件、被压缩/轻化的零部件、多实体零件
· 批量扫描整个文件夹：递归找出所有 .sldprt / .sldasm，逐个检查
· 导出 CSV 报表：可用 Excel 打开，中文不乱码

为什么有用：SolidWorks 一次只能看一个文件。「什么错」对话框也是单文档。
想知道"这一整个文件夹里哪些模型有问题"，原生功能做不到。


二、系统要求
------------
· Windows 10 / 11
· SolidWorks 2025（版本 33.x）—— 其他版本不保证可用
· .NET Framework 4.8（Win10 1903 以上系统自带）
· 安装时需要管理员权限（写注册表）


三、安装
--------
1. 重要：如果这个压缩包是从网上下载的，先右键 zip → 属性 → 勾选"解除锁定"→ 确定，
   再解压。否则 Windows 会阻止 .NET 加载 DLL。
2. 完全关闭 SolidWorks。
3. 右键 install.cmd → 以管理员身份运行（脚本也会自己申请提权）。
4. 启动 SolidWorks → 工具 → 插件 → 勾选 "Model Inspector"。
5. 会弹出一个"模型体检"窗口。

注意：DLL 必须和这几个 Interop 程序集放在同一目录（压缩包里已经配好），
不要单独把 SwAiGuide.dll 拷走。


四、使用
--------
· 扫描当前文档：打开一个零件/装配体，点按钮即可。
· 批量扫描：点"批量扫描文件夹"，选目录，等进度条走完。
  扫描过程中 SolidWorks 会短暂打开每个文件（这是必须的，因为要读特征树），
  扫完会自动关闭，不会保存任何修改。
· 导出 CSV：扫描完成后点"导出"。

速度参考：普通零件 3-4 秒/个，复杂零件（比如 40+ 特征）约 10 秒/个。


五、卸载
--------
关闭 SolidWorks → 右键 uninstall.cmd → 以管理员身份运行。


六、出问题怎么办
----------------
先看日志：
  %LOCALAPPDATA%\SwAiGuide\addin.log

常见情况：

1) 插件列表里找不到 "Model Inspector"
   - 确认是用管理员身份运行的 install.cmd
   - 确认安装前完全关闭了 SolidWorks（否则 regasm 会失败）

2) 出现 "未能加载文件或程序集" 或 "0x80131515"
   - 说明 DLL 被 Windows 标记为"来自网络"
   - 对该目录下所有 .dll 执行：Unblock-File 命令，或右键属性解除锁定

3) 批量扫描某些文件失败，提示"文件不存在"
   - 通常是路径过长（超过 260 字符）或中文层级过深
   - 把文件挪到更浅的目录再试

4) 扫描时 SolidWorks 窗口跳到前台
   - 这是通过 SolidWorks 打开文件的固有行为，无法完全避免
   - 扫完会自动切回你原来的文档


七、已知限制
------------
· 只支持 SolidWorks 2025
· 批量模式只检查装配体的顶层零部件，不递归进子装配体内部
· 必须打开文件才能读特征信息，所以无法做到"秒扫"
· 不做干涉检查（那需要额外的几何计算，速度会慢很多）


八、文件清单
------------

SolidWorks.Interop.sldworks.dll     SolidWorks API 互操作（必须同目录）
SolidWorks.Interop.swconst.dll      常量定义
SolidWorks.Interop.swpublished.dll  加载项接口
install.cmd / uninstall.cmd         安装 / 卸载
